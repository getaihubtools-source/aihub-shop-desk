# انتشار نسخه‌ی جدید (سیستم آپدیت)

قبل از هر بار push روی GitHub Pages فقط یک دستور بزن:

    python3 tools/stamp.py

- شناسه‌ی نسخه (`BUILD`) از روی محتوای فایل‌ها ساخته و در `service-worker.js`، هر دو صفحه‌ی HTML و `version.json` نوشته می‌شود.
- اگر چیزی تغییر نکرده باشد، هیچ فایلی عوض نمی‌شود (آپدیت الکی ساخته نمی‌شود).
- اگر stamp را فراموش کنی، صفحه‌ها باز هم آپدیت می‌شوند، ولی تشخیص نسخه‌ی جدید دقیق نیست. حتماً قبل از انتشار اجرا کن.
- `tools/` روی Pages هم منتشر می‌شود؛ ایرادی ندارد (SW آن را کش نمی‌کند).

رفتار برای کاربر: اپ/APK هر ۱۵ دقیقه، موقع برگشتن به برنامه و بعد از وصل شدن اینترنت نسخه را چک می‌کند و نوار «نسخه‌ی جدید آماده است» نشان می‌دهد. اگر برنامه بیش از ۱ دقیقه در پس‌زمینه بوده و پنجره‌ای باز نباشد، خودکار آپدیت می‌شود. دکمه‌ی «بررسی بروزرسانی» در تنظیمات → درباره.
